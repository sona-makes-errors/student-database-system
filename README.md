# student-database-system
A menu-driven student Database system to add the student's info, update, delete and display. might not save the data longer than a day, to save changes should be linked to google_drive. 
## Features
- Add student records
- View all students
- Search by names
- Update marks
- Delete a student
- Input validation with error handling (invalid name, marks out of range)
## Tevh used
- Python
- SQLite3
